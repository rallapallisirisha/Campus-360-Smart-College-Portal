# 🏫 Campus 360 – Smart College Portal

Campus 360 is a beginner-friendly Python console application designed to provide a simple and centralized college portal.

## ✨ Features

- 👨‍🎓 Student Login
- 👩‍🏫 Faculty Login
- 👨‍💼 Admin Login
- 📝 New Student Registration
- 🏫 Explore College
- ❓ Help Section
- 🚪 Exit

## 🛠️ Technologies Used

- Python
- VS Code

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Open `miniproject.py`.
4. Run the Python file.
5. Follow the menu options displayed on the screen.

## 📚 Project Concepts

This project uses:

- Variables
- Input and Output
- Conditional Statements
- Loops
- Functions
- Menu-driven Programming
- Basic Validation
